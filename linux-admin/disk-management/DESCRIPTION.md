In this challenge you will learn about basic disk management tools on Linux.

### Common Tools
- `df` is a tool used to report file system usage information.
  - Running `df -h` will show disk usage in a human-readable format
  
- `lsblk` is a tool used to show disks and their partitions
  - Running `lsblk` will show a list of disks on the system and their partitions, as well as where they are mounted.
  
- `du` is a tool used to show how much disk space is used by a directory.
  - Running `du -h` will show how much disk space the current directory is using
    in a human-readable format
    
This challenge will have you run these common tools to try them out!
Run `/challenge/solve` to get further instructions!
